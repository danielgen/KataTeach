# Documentation

This directory contains the experiment documentation.

## Current study documentation

- [Experiments and results](VALIDITY_V5_EXPERIMENTS_AND_RESULTS.md) is the
  authoritative account of the validity-v5 design, results, and limitations.
- [Validity-v5 runbook](VALIDITY_V5_RUNBOOK.md) explains when existing games
  must be retained and what is required to rerun the pipeline.
- [Tenuki intervention analysis](TENUKI_INTERVENTION_ANALYSIS.md) records the
  confirmatory causal result and the later exploratory F1/F5 diagnostics.

## Feature and interface references

- [Snorkel position features](SNORKEL_FEATURES_DOCUMENTATION.md) describes the
  current feature families and thresholds.
- [Feature data flow](FEATURE_VERIFICATION.md) describes the boundary between
  Python feature output and the browser visualization.
- [Interactive board](README_interactive_board.md) covers the notebook board.

## Legacy exploratory workflows

- [Linear probes and game commentary](LINEAR_PROBES_WORKFLOW.md) describes the
  deprecated exploratory workflow.
- [Activation manipulation](ACTIVATION_MANIPULATION.md) describes an older
  exploratory intervention tool. It is not the validated-v5 causal procedure.

Legacy commands require locally generated games and probe artifacts and should
not be used as evidence for the validated results.
